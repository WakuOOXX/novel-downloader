三步上手

Windows 用户下载即用,无需安装 Python

下载并解压

获取上方 Windows 版压缩包,解压后保持 小说下载器.exe 与 bookSource.json 在同一文件夹。

搜索书名

双击打开,输入书名点搜索。想更快可在顶部只选「校验可用 / 笔趣阁0905」等分组。

导出双格式

双击结果行即开始下载,完成后自动打开目录 —— TXT + EPUB 都在里面。

从源码运行 / 自行构建

需要 Python 3.13+ 与 tkinter;引擎模块 legado/ 可脱离 GUI 单独使用

pip install requests beautifulsoup4 lxml
python app.py                # 运行 GUI
python e2e2.py 书名 书源域名  # 全链路自检(含 EPUB 结构校验)

# 打包单文件 EXE
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name 小说下载器 app.py

详细实现见仓库内 技术文档.md(13 章:规则引擎、架构、导出格式、扩展指引)。
